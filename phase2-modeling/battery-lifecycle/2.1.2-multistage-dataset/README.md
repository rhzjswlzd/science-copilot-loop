### 容量衰减曲线

电池在整个生命周期中经历了两种类型的测试：**日常循环**（ZYK 文件）和**定期检查**（CU/exCU 文件）。这两种数据的区别在于：

- **日常循环**：部分充放电（DOD < 100%），模拟实际使用场景，连续运行无休息
- **定期检查**：完整充放电（DOD = 100%），标准化测试（C/20，23°C），测试前有休息恢复期

下图展示了学术界对这种测试策略的常用绘图方法。其中 **Method 3（双Y轴）** 同时展示了两种数据：蓝点表示 RPT 检查点的完整容量（~4.8 Ah），红点表示日常循环的部分容量（~0.7 Ah）。可以观察到蓝点始终略高于红点，这是因为 RPT 前有休息恢复期，消除了浓差极化，而日常循环是连续运行，存在累积疲劳效应。

![容量衰减曲线对比](./figures/academic_plotting_methods.png)

**关键观察**：
1. RPT 检查点（蓝色）提供标准化的容量基准，用于准确评估电池健康状态
2. 循环数据（红色）反映实际使用中的表现，容量略低是正常现象
3. 两种数据的归一化衰减趋势一致，验证了数据的内部一致性
4. Method 4 展示了相对容量随循环数的变化，是顶刊论文的常用形式

### 充放电特性曲线

从一个 RPT 检查点（exCU 文件）中提取了完整的充放电数据，绘制电压-容量曲线。红色曲线为放电过程（电压从 4.2V 降至 2.5V），蓝色曲线为充电过程（电压从 2.8V 升至 4.2V）。

![充放电特性曲线](./figures/charge_discharge_curves.png)

**关键参数**：
- **放电容量**：4.790 Ah
- **充电容量**：4.772 Ah
- **库仑效率**：100.39%（略大于 100% 是因为测量误差和电极表面副反应）
- **充电平台电压**：3.940 V
- **放电平台电压**：3.498 V
- **电压极化**：0.442 V（充放电电压差，反映内阻和极化效应）

两条曲线形成典型的"香蕉形"滞回环，这是由电池的内阻和电化学极化导致的。充电时需要更高的电压克服极化，放电时电压则受到极化影响而降低。

### 增量容量分析（dQ/dV）

dQ/dV 曲线是一种强大的诊断工具，通过对 V-Q 曲线求导，可以放大电压平台的细微特征。峰值位置对应电化学相变点（如正极材料的脱锂/嵌锂平台），峰值高度反映活性材料的容量，峰值位置的漂移则指示极化增加和老化程度。

![增量容量分析](./figures/dqdv_curves.png)

**应用价值**：
- **健康状态诊断**：峰值高度降低表明活性材料损失
- **老化机理分析**：峰值位置向左/右漂移反映阻抗增加或相变温度变化
- **SOC 估计**：峰值位置对应特定的 SOC 区间
- **异常检测**：峰形畸变或新峰出现可能指示内部短路或副反应

**观察到的特征**：
- 放电曲线（红色）和充电曲线（蓝色）均呈现明显的峰值结构
- 峰值位置差异反映了充放电过程中的动力学差异
- 数据经过 20 点移动平均平滑处理，消除了高频噪声

## 🎯 预测任务设计

### 目标变量

**方案 1：总循环寿命（FEC）**  
从 ZYK 文件提取总等效完整循环数（Full Equivalent Cycles）

**方案 2：容量衰减到 80% 的循环数**  
从 CU/exCU 文件提取容量轨迹，计算到达 80% 阈值的循环数

**方案 3：容量衰减速率**  
线性拟合容量-循环数曲线，提取斜率（mAh/圈）

### 输入特征

**1. 实验条件特征（5个）**：
- 环境温度（Tamb）
- 最大 SOC（soc_max）
- 放电深度（DOD）
- 充电倍率（c_ch）
- 放电倍率（c_dch）

**2. 早期时序特征**（从前 10/50/100 圈提取）：

| 特征类别 | 具体特征 | 来源 |
|----------|----------|------|
| **容量特征** | 容量衰减量、衰减速率、容量保持率 | CU/exCU |
| **电压特征** | OCV 曲线统计量（均值、方差、峰值） | ZYK/CU |
| **dQ/dV 特征** | 增量容量曲线统计量（最小值、最大值、方差、峰值位置） | ZYK/CU |
| **内阻特征** | DCIR（直流内阻）变化趋势 | ET |
| **温度特征** | 表面温度统计量（均值、最大值、标准差） | ZYK |

## 🧪 实验方案

### 数据划分

**方案 A：随机划分**（80/20）
- 优点：简单，样本独立性好
- 缺点：可能导致数据泄漏（同一测试点的电池分散到训练/测试集）

**方案 B：按测试点分组**（推荐 ✅）
- 训练集：TP_z01 ~ TP_z20（20 个测试点，60 颗电池）
- 测试集：TP_z21 ~ TP_z25（5 个测试点，15 颗电池）
- 优点：避免数据泄漏，验证泛化能力
- 缺点：测试集较小

## 🎯 实验结果：1000圈容量保持率预测

### 研究目标

**利用电池早期循环数据（前3次CU + 第1次exCU），预测1000圈和2000圈时的容量保持率。**验证早期特征对长期性能预测的有效性，并对比不同机器学习算法在小样本场景下的表现。

### 特征工程

#### 核心特征（10个）

通过相关性分析（删除 |r| > 0.9 的冗余特征），从原始提取的特征中筛选出以下核心特征：

| 类别 | 特征 | 物理意义 |
|------|------|----------|
| **实验条件** (5) | amb_temp | 环境温度（°C） |
| | soc_max | 最大充电状态（%） |
| | dod | 放电深度（%） |
| | c_ch | 充电倍率（C） |
| | c_dch | 放电倍率（C） |
| **容量** (2) | Q_check1 | 第1次检查容量（Ah） |
| | capacity_retention | 第3次/第1次容量比（%） |
| **电压** (2) | V_mean_avg | 前3次CU平均放电电压（V） |
| | V_std_avg | 前3次CU放电电压标准差（V） |
| **温度** (1) | T_surf_mean | 表面温度均值（°C） |

**优化说明**：删除了高度相关的特征（如 Q_check2与Q_check1相关性0.954，capacity_fade_early与capacity_retention相关性1.000），在减少过拟合风险的同时保留了关键信息。

### 模型对比

#### 算法选择

| 算法 | 超参数搜索 | 选择理由 |
|------|-----------|----------|
| **Ridge回归** | alpha ∈ {0.1, 1.0, 10.0, 100.0} | L2正则化，适合小样本 |
| **Random Forest** | n_estimators ∈ {50,100,200}<br>max_depth ∈ {5,10,None} | 非线性建模 |
| **Gradient Boosting** | learning_rate ∈ {0.01,0.1}<br>max_depth ∈ {3,5} | 集成学习 |

#### 性能对比（测试集，17样本）

| 模型 | MAPE (%) | RMSE | R² | MAE |
|------|---------|------|-----|-----|
| **Ridge (α=10.0)** | **0.85** ✅ | **0.998** ✅ | **0.138** ✅ | **0.813** ✅ |
| Gradient Boosting | 2.01 | 2.654 | -5.099 ❌ | 1.933 |
| Random Forest | 2.10 | 2.718 | -5.398 ❌ | 2.016 |

**关键发现**：
- Ridge回归在所有指标上均优于树模型
- R²为正值（0.138）说明模型具有预测能力
- 树模型R²为负，说明预测效果甚至不如简单使用均值
- **在小样本场景（50个训练样本）下，强正则化的线性模型优于复杂的非线性模型**

### 结论与讨论

#### 主要结论

1. **早期特征具有较强的预测能力** — 仅使用前3次容量检查和第1次扩展检查的数据，即可准确预测1000圈时的容量保持率（MAPE=0.85%）

2. **特征精简提升模型性能** — 通过相关性分析精简特征，在减少过拟合风险的同时保留了关键信息

3. **Ridge回归在小样本场景下优于树模型** — 在仅有50个训练样本的情况下，强正则化的线性模型比Random Forest和Gradient Boosting更稳健

4. **模型具有良好的长期外推能力** — 对4000圈样品的预测误差小于1%，说明模型泛化性能优秀

#### 局限性

- 2000圈预测的训练样本过少（仅18个），预计模型性能会下降
- 数据集中大部分电池（93%）测试结束时仍保持>90%容量，真实失效数据不足
- 模型主要基于线性假设，可能无法捕捉复杂的非线性老化模式
