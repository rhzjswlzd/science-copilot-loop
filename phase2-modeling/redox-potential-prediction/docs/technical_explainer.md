## 1. 项目定位

本项目是一个 **AI for Science (AI4S)** 的实践案例，展示如何用机器学习方法加速材料科学研究。

具体任务：训练一个模型，**输入有机分子的结构描述（SMILES），输出其氧化还原电位的预测值**。

这件事的意义在于：传统方法评估一个分子的电化学性能需要数小时的量子化学计算（DFT）或数天的合成+实验，而训练好的 ML 模型可以在**毫秒内**给出估算，将筛选效率提升数十万倍。

---

## 2. 核心问题

### 2.1 什么是氧化还原电位

氧化还原电位（Redox Potential）描述的是一个分子**得到或失去电子的倾向**，以伏特（V）为单位。

- **还原电位**高 → 分子容易得到电子 → 适合做正极材料
- **氧化电位**高 → 分子容易失去电子

这个数值直接决定了一个分子能否作为电池的电极材料、以及电池的工作电压。

### 2.2 传统评估方法的瓶颈

| 方法 | 原理 | 耗时 | 精度 | 可扩展性 |
|---|---|---|---|---|
| 实验合成+电化学测试 | 直接测量 | 数天/分子 | 金标准 | ❌ 极差 |
| DFT 量子化学计算 | 数值求解薛定谔方程 | 数小时/分子 | 较高 (误差 ~0.1-0.3V) | ⚠️ 一般 |
| **ML 预测（本项目）** | 从数据中学习规律 | **毫秒/分子** | **中等 (误差 ~0.35V)** | **✅ 极好** |

### 2.3 我们的策略

用已有的 DFT 计算结果作为训练数据，让 ML 模型学习"分子结构 → 电位"的映射关系。训练一次后，就可以对任意新分子做瞬时预测。

本质上，这是一种**代理模型（Surrogate Model）**方法 — 用快而粗的模型替代慢而精的计算，服务于初筛场景。

## 3. 数据集：OMEAD

### 3.1 来源

**OMEAD**（Organic Materials for Energy Applications Database）由巴西研究团队构建并开源。

- 论文：[DOI: 10.1016/j.ensm.2021.10.029](https://doi.org/10.1016/j.ensm.2021.10.029)
- 代码：[github.com/rpcarvs/anima](https://github.com/rpcarvs/anima)

### 3.2 规模与内容

| 属性 | 值 |
|---|---|
| 分子总数 | 26,218 |
| 分子类型 | 有机小分子 |
| 计算方法 | DFT (B3LYP 泛函) |
| 溶剂模型 | SMD (乙腈, acetonitrile) |
| 电位参考 | vs. vacuum (真空) |

### 3.3 数据结构

每个分子记录了以下信息：

| 列名 | 含义 | 单位 | 角色 |
|---|---|---|---|
| `smiles` | 分子结构编码 | — | **输入** |
| `reduction_solv` | 乙腈中的还原电位 | V (vs. vacuum) | **预测目标** |
| `oxidation_solv` | 乙腈中的氧化电位 | V (vs. vacuum) | 可选目标 |
| `homo` / `lumo` | 前线轨道能量 | Hartree | DFT 描述符 |
| `ip_solv` / `ea_solv` | 电离能 / 电子亲和能 | V | DFT 描述符 |
| `capacity` | 比容量 | mAh/g | 可选目标 |
| `redox_stable` | 氧化还原稳定性 | yes/no | 分类标签 |

### 3.4 为什么选这个数据集

1. **自带 SMILES** — 无需反查或转换
2. **规模合适** — 26K 分子对 ML 训练是合理的数据量
3. **计算条件统一** — 所有分子用同一方法，数据一致性好
4. **聚焦电极材料** — 直接服务于电池材料筛选场景

### 3.5 数据质量

- 26,218 个分子中，26,205 个可被 RDKit 正常解析（99.95%）
- 13 个无法解析的分子因 SMILES 中存在化学价不合法的结构，被自动排除
- 无缺失值

## 4. 分子的数字化表示：SMILES

### 4.1 什么是 SMILES

SMILES（Simplified Molecular Input Line Entry System）是一种将分子的二维结构编码为一行文本的标准化方法。

基本规则：

| 规则 | 写法 | 含义 |
|---|---|---|
| 原子直接写 | `C` | 甲烷（氢原子省略） |
| 相邻 = 成键 | `CCO` | 乙醇 (C-C-O) |
| `=` 双键 | `C=O` | 甲醛的羰基 |
| 数字闭合环 | `C1CCCCC1` | 环己烷 |
| 小写 = 芳香 | `c1ccccc1` | 苯 |
| 括号 = 支链 | `CC(C)C` | 异丁烷 |

常见分子的 SMILES：

```
水:        O
乙醇:      CCO
苯:        c1ccccc1
苯醌:      O=C1C=CC(=O)C=C1      ← 典型的氧化还原活性分子
阿司匹林:  CC(=O)Oc1ccccc1C(O)=O
```

### 4.2 SMILES 的特点

- **人可读**：熟练者看到 `c1ccccc1` 可以直接识别为苯
- **机器可读**：RDKit 等工具库可直接解析
- **紧凑**：复杂分子也只需一行字符串
- **可逆**：SMILES ↔ 分子结构图可以相互无损转换
- **标准化**：通过 canonicalization 可以保证同一分子只有一种写法

### 4.3 为什么不能直接用 SMILES 训练

ML 模型需要**固定长度的数值向量**作为输入。SMILES 是变长字符串，不同分子长度不同，字符本身也没有数值含义。

因此需要一个转换步骤：**SMILES → 数值特征向量**（特征工程）。

我们在本项目中实现了两种不同的转换策略：

## 5. 特征工程：将分子变成数字

### 策略概览

| 策略 | 方案 A (XGBoost) | 方案 B (Chemprop) |
|---|---|---|
| **特征提取** | 人工设计：Morgan FP + 描述符 | 端到端自动学习 |
| **输入形式** | 2058 维固定向量 | 分子图（原子=节点，键=边） |
| **可训练？** | 否，特征是固定算法算出的 | 是，编码器和预测器联合训练 |

### 5.1 Morgan Fingerprint（方案 A 使用）

Morgan Fingerprint 的核心思想是：**描述每个原子的"邻域环境"**。

具体过程：
1. 对分子中每个原子，考察以它为中心、半径 r=2（即 2 层化学键范围内）的所有邻居
2. 将这个邻域的信息（原子类型、键类型、环信息）通过哈希函数映射为一个整数
3. 这个整数对 2048 取模，得到一个位编号（0~2047）
4. 把这个位设为 1
5. 对所有原子重复上述过程
6. 结果：一个长度 2048 的 0/1 向量

直觉理解：向量的每一位表示"分子中是否存在某种特定的局部结构片段"。两个分子的 fingerprint 越相似，说明它们的局部结构越接近。

### 5.2 RDKit 物化描述符（方案 A 使用）

在 fingerprint 之外，我们还计算了 10 个全局分子属性作为补充：

| 描述符 | 含义 | 与电位的可能关联 |
|---|---|---|
| MolWt | 分子量 | 影响容量和溶解性 |
| LogP | 亲油/亲水性 | 溶剂化行为 |
| TPSA | 极性表面积 | 与溶剂化能量相关 |
| NumHDonors / Acceptors | 氢键供/受体数 | 分子间相互作用 |
| NumRotatableBonds | 可旋转键数 | 分子柔性 |
| NumAromaticRings | 芳香环数 | 芳香性与氧化还原活性密切相关 |
| NumHeavyAtoms | 非氢原子数 | 分子大小 |
| RingCount | 环总数 | 结构复杂度 |
| FractionCSP3 | SP3 碳占比 | 饱和度 |

最终特征：Morgan FP（2048 维）+ 描述符（10 维）= **2058 维向量**。

### 5.3 分子图（方案 B 使用）

Chemprop 不使用预计算的 fingerprint，而是将分子表示为一个**图（Graph）**：

- **节点（Node）**= 原子，每个节点带有原子类型、形式电荷、是否芳香等属性
- **边（Edge）**= 化学键，每条边带有键类型（单/双/三/芳香）、是否在环中等属性
- 图的结构就是分子的拓扑结构

然后由神经网络自动学习如何将这个图编码为一个固定长度的向量。

## 6. 方案 A：XGBoost + Morgan Fingerprint

### 6.1 XGBoost 是什么

XGBoost（eXtreme Gradient Boosting）是一种集成学习算法，通过串行累加多棵决策树来逼近目标函数。

工作原理：
- 第 1 棵树给出粗略预测
- 第 2 棵树专门学习第 1 棵树的**预测残差**（预测不准的部分）
- 第 3 棵树修正前 2 棵的累积残差
- ...
- 500 棵树叠加后，残差被逐步减小到很低

这种"逐步纠错"的策略使得最终的集成模型远强于任何一棵单独的树。

### 6.2 超参数设置

| 参数 | 值 | 含义 |
|---|---|---|
| n_estimators | 500 | 决策树总数 |
| max_depth | 6 | 单棵树最大深度（限制复杂度，防过拟合） |
| learning_rate | 0.1 | 每棵新树的权重（越小越保守） |
| subsample | 0.8 | 每棵树随机使用 80% 的数据（引入随机性） |
| colsample_bytree | 0.8 | 每棵树随机使用 80% 的特征（同上） |

### 6.3 训练流程

```
26,205 有效分子
    ↓
SMILES → RDKit → 2058 维特征向量
    ↓
80/20 划分 → 训练集 20,964 + 测试集 5,241
    ↓
5-Fold 交叉验证 (CV MAE = 0.3773V, CV R² = 0.7061)
    ↓
训练最终模型 → 测试集评估
```

### 6.4 结果

| 指标 | 数值 |
|---|---|
| 测试集 MAE | **0.3721 V** |
| 测试集 RMSE | 0.5763 V |
| 测试集 R² | 0.7028 |
| 训练时间 | ~3 分钟 (CPU) |

## 7. 方案 B：Chemprop D-MPNN（图神经网络）

### 7.1 和方案 A 的根本区别

方案 A 的流程是"人工设计特征 → 传统 ML"，分为两个独立阶段。
方案 B 的流程是"端到端学习" — 模型同时学**怎么编码分子**和**怎么预测电位**。

```
方案 A：SMILES → [固定算法] → 2058维向量 → [XGBoost] → 电位
方案 B：SMILES → [分子图] → [D-MPNN 自动编码] → [FFN] → 电位
                              ↑ 这部分是可训练的
```

### 7.2 D-MPNN 的工作原理

D-MPNN（Directed Message Passing Neural Network）分为 4 个模块：

**① 构建分子图**
- 每个原子成为一个节点，每个化学键成为两条有向边（A→B 和 B→A）
- 节点和边各自带有初始特征向量（编码原子/键的化学性质）

**② 消息传递（核心）**
- 每条有向边维护一个隐藏向量 h
- 迭代 T 轮（默认 3 轮），每轮更新规则：

  ```
  h(边A→B, 第t+1轮) = 聚合(所有指向A的边的 h) + 边A→B的初始特征
  ```

- 直觉：每轮传递后，每个原子"感知"到更远范围的结构信息
  - 第 1 轮：知道直接邻居
  - 第 2 轮：知道 2 步之内的邻居
  - 第 3 轮：知道 3 步之内的邻居

**③ 聚合**
- 将所有原子的最终向量求均值，得到一个代表整个分子的向量
- 这个向量可以理解为"由神经网络自动学出的最优 fingerprint"

**④ 前馈网络 (FFN)**
- 一个简单的全连接神经网络，将分子向量映射为最终的电位预测值

**为什么叫"有向"消息传递？**
传统 GNN 在原子之间传递消息，会导致信息回流（A→B→A，消息绕一圈回到起点）。D-MPNN 改为在有向边之间传递，避免了这种信息冗余。这是 Chemprop 的技术创新之一。

### 7.3 模型结构

| 模块 | 类型 | 参数量 |
|---|---|---|
| message_passing | BondMessagePassing | 227K |
| agg | MeanAggregation | 0 |
| bn | BatchNorm1d | 600 |
| predictor | RegressionFFN | 90.6K |
| **总计** | | **318K** |

### 7.4 训练配置

| 配置 | 值 |
|---|---|
| Epochs | 30 |
| Batch size | 64 |
| 硬件 | NVIDIA GTX 1650 (4GB) |
| 框架 | PyTorch 2.5.1 + Lightning |
| 训练时间 | ~7 分钟 |

### 7.5 结果

| 指标 | 数值 |
|---|---|
| 测试集 MAE | **0.3478 V** |
| 测试集 RMSE | 0.5746 V |
| 测试集 R² | 0.7045 |

## 8. 两种方案对比

使用同一数据集、同一 train/test 划分（random_state=42），确保公平对比。

| 维度 | XGBoost + Morgan FP | Chemprop D-MPNN | 说明 |
|---|---|---|---|
| **MAE** | 0.3721 V | **0.3478 V** ↓6.5% | D-MPNN 更准 |
| **RMSE** | 0.5763 V | **0.5746 V** | 几乎相同 |
| **R²** | 0.7028 | **0.7045** | 几乎相同 |
| **需要特征工程** | ✅ 是 | ❌ 否 | D-MPNN 端到端 |
| **可解释性** | 中等（有 feature importance） | 较低 | XGBoost 更透明 |
| **训练速度** | ~3 min (CPU) | ~7 min (GPU) | XGBoost 更快 |
| **硬件需求** | 无 GPU 要求 | 需要 GPU（CPU 也可但慢） | XGBoost 更低 |
| **模型大小** | ~14 MB | ~1.3 MB | D-MPNN 更紧凑 |
| **调参复杂度** | 低 | 中等 | — |

### 关键结论

1. **D-MPNN 的端到端学习确实优于固定的 Morgan FP**，但在这个数据集和规模上，优势幅度不大（约 6.5%）
2. 两种方案各有适用场景：
   - 需要快速原型验证、可解释性要求高 → **XGBoost**
   - 需要最优精度、不想做特征工程 → **D-MPNN**
3. 实际应用中，两个模型可以做 **ensemble**（取平均或加权），通常能进一步提升精度

## 9. 模型评估指标解读

### 9.1 MAE（Mean Absolute Error）

$$\text{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$$

所有样本的预测误差的绝对值的平均。MAE = 0.35V 意味着平均每个分子的电位预测**偏离真实值约 0.35V**。

### 9.2 RMSE（Root Mean Squared Error）

$$\text{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$$

对大误差更敏感（因为取了平方）。RMSE 明显大于 MAE 时，说明存在少量误差很大的样本。

### 9.3 R²（决定系数）

$$R^2 = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$

- R² = 1.0：完美预测
- R² = 0.0：模型和"直接预测均值"一样差
- R² = 0.70：模型解释了目标变量**70% 的变异**

### 9.4 如何理解我们的结果

OMEAD 数据中还原电位范围约 -0.85V ~ 10.14V（跨度 ~11V）。

MAE ≈ 0.35V 相当于在 11V 范围内约 **3.2% 的误差率** — 对于初筛场景已有实用价值。

对比参考：
- DFT 计算本身 vs 实验值的误差 ≈ 0.1-0.3V
- 我们用纯 2D 结构信息（不做 DFT）达到 ≈ 0.35V，代价是速度快了 ~100 万倍

### 9.5 可视化评估怎么看

**散点图（Prediction vs Ground Truth）**：所有点越靠近 y=x 对角线，预测越准。离群点 = 模型"不擅长"的分子类型。

**残差分布图**：以 0 为中心的钟形曲线 = 没有系统性偏差。偏向正/负 = 系统性高估/低估。

## 10. 从训练到推理：模型如何使用

### 10.1 训练阶段（一次性）

```
OMEAD CSV → 清洗 → 特征提取 → train/test 划分 → 模型训练 → 保存 .pkl
```

### 10.2 推理阶段（可重复使用）

```
用户输入 SMILES（如 "O=C1C=CC(=O)C=C1"）
    ↓
RDKit 解析 → 分子对象                   (~1ms)
    ↓
计算 Morgan FP + 描述符                  (~1ms)
    ↓
XGBoost .predict()                      (~0.1ms)
    ↓
输出：2.69 V (vs. vacuum, acetonitrile)
```

总耗时约 **2 毫秒**。

### 10.3 重要说明

- 预测时**不需要任何数据库查询**，也不需要联网
- 可以预测**任意有机分子**，包括从未合成过的假想分子
- 只要能写出合法的 SMILES 字符串就行
- 预测的**可靠程度**取决于新分子和训练数据中分子的结构相似度

## 11. 局限性与改进方向

### 11.1 当前局限

| 局限 | 说明 |
|---|---|
| 仅使用 2D 结构信息 | 忽略了 3D 构象对电位的影响 |
| 训练数据均为 DFT 计算值 | 没有实验验证，存在系统偏差 |
| 泛化性有限 | 对训练集中未覆盖的分子类型可能不准 |
| 无不确定性估计 | 模型只输出点预测，不知道"有多不确定" |

### 11.2 改进路径

| 层次 | 方向 | 预期效果 | 投入 |
|---|---|---|---|
| 1 | 全量 RDKit 描述符 (~200个) + 自动筛选 | MAE 降低 ~0.02V | 1-2 天 |
| 2 | 增加训练轮数 / ensemble 多模型 | MAE 降低 ~0.03V | 1 天 |
| 3 | 预训练分子 Transformer（MolBERT 等） | 可能大幅提升 | 1-2 周 |
| 4 | 引入 3D 构象信息 | 捕获构象效应 | 2-4 周 |
| 5 | 不确定性量化（ensemble / MC-dropout） | 给出置信区间 | 3-5 天 |
| 6 | 实验闭环验证 | 真正的科研价值 | 数月 |

## 13. 术语表

| 术语 | 解释 |
|---|---|
| **AI4S** | AI for Science，用 AI 方法加速科学研究 |
| **SMILES** | 将分子 2D 结构编码为文本字符串的标准格式 |
| **DFT** | 密度泛函理论，一种量子化学数值计算方法 |
| **RDKit** | 开源化学信息学工具库，用于分子结构解析和特征计算 |
| **Morgan Fingerprint** | 一种分子指纹方法，将原子邻域通过哈希映射为固定长度的位向量 |
| **XGBoost** | 梯度提升决策树算法，通过累加多棵弱决策树逼近目标 |
| **D-MPNN** | 有向消息传递神经网络，在化学键（而非原子）之间传递信息的图神经网络 |
| **Chemprop** | MIT 开源的分子性质预测框架，基于 D-MPNN 架构 |
| **MAE** | 平均绝对误差，预测偏差的最直观度量 |
| **RMSE** | 均方根误差，对大误差更敏感 |
| **R²** | 决定系数，表示模型解释了目标变量变异的百分比 |
| **交叉验证 (CV)** | 多次划分训练/验证集取平均，获得更稳健的评估结果 |
| **过拟合** | 模型"记住"训练数据而非学到泛化规律，导致在新数据上表现差 |
| **vs. vacuum** | 电位以真空能级为零点。转为 vs. SHE 约减去 4.28V |
| **QSPR** | 定量构效关系，通过分子结构定量预测物理化学性质的方法论 |
| **代理模型** | 用快速近似模型替代耗时的精确模拟，常见于工程优化和材料筛选 |
| **端到端学习** | 模型自动学习从原始输入到最终输出的完整映射，不需要人工设计中间环节 |
